# tools

`uasm-macos` and `uasm-linux` are platform-specific [UASM](https://github.com/Terraspace/UASM)
binaries used to assemble the MASM-style source files in this repository. The
Linux binary comes from the official [UASM v2.57 release](https://github.com/Terraspace/UASM/releases/tag/v2.57r),
and the macOS binary comes from the [UASM macOS build](https://github.com/upiter/uasmac).

UASM is distributed under the Sybase Open Watcom Public License; a copy is
included in [`UASM-LICENSE.txt`](UASM-LICENSE.txt).

UASM source code is available in the [official UASM repository](https://github.com/Terraspace/UASM).
